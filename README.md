# metaSCORE — pobieranie

Aktualna wersja pilotażowa: **0.4.4**, macOS 13 lub nowszy, wyłącznie Apple Silicon.

[Pobierz instalator DMG](https://github.com/Mikalakis/metascore-releases/releases/download/v0.4.4/metaSCORE-0.4.4-arm64.dmg) · [Informacje o wydaniu](https://github.com/Mikalakis/metascore-releases/releases/tag/v0.4.4)

Przenieś aplikację do folderu Aplikacje przed pierwszym uruchomieniem. Użytkownicy starszego metaSCORE otrzymają obowiązkową aktualizację przy uruchomieniu: jedno kliknięcie OK, pobranie i restart. Projekty oraz lokalna historia pozostają.

Google Drive: jeden projekt edytuje jedna osoba naraz. Przed przekazaniem zapisz i zamknij projekt, a następnie poczekaj na pełną synchronizację obu laptopów. Równoczesna edycja na dwóch laptopach nie jest obsługiwana.

Kanał zawiera podpisany manifest i czyste instalatory, bez dokumentów produkcyjnych i sekretów. Starsze wydania zostały wycofane z publicznego pobierania. To pilotaż, nie wydanie produkcyjne 1.0.
