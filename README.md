# metaSCORE Releases

Publiczny kanał podpisanych aktualizacji aplikacji metaSCORE.

To repozytorium zawiera wyłącznie manifest wersji i gotowe instalatory. Nie zawiera dokumentów produkcyjnych, danych projektów, kluczy API ani innych sekretów. Kod źródłowy pozostaje w prywatnym repozytorium.

Aktualne wydanie pilotażowe: 0.4.0 (macOS, Apple Silicon).
