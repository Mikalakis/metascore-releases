# metaSCORE — pobieranie

Aktualna wersja pilotażowa: **0.4.5**, macOS 13 lub nowszy, wyłącznie Apple Silicon.

[Pobierz aplikację (DMG)](https://github.com/Mikalakis/metascore-releases/releases/download/v0.4.5/metaSCORE-0.4.5-arm64.dmg) · [Pobierz instrukcję obsługi](https://github.com/Mikalakis/metascore-releases/releases/download/v0.4.5/START_TUTAJ.txt) · [Informacje o wydaniu](https://github.com/Mikalakis/metascore-releases/releases/tag/v0.4.5)

Formularz nowego projektu zawiera Kierownika Produkcji i Producenta, bez osobnego pola Operator. Osoba przygotowująca dane przypisywana jest z zalogowanego konta.

Przenieś aplikację do folderu Aplikacje przed pierwszym uruchomieniem. Użytkownicy starszego metaSCORE otrzymają obowiązkową aktualizację przy uruchomieniu: jedno kliknięcie OK, pobranie i restart. Projekty i lokalna historia pozostają.

Google Drive: jeden projekt edytuje jedna osoba naraz. Przed przekazaniem zapisz i zamknij projekt oraz poczekaj na pełną synchronizację obu laptopów. Równoczesna edycja na dwóch laptopach nie jest obsługiwana.

Instalator jest podpisany i notaryzowany, bez dokumentów produkcyjnych i sekretów. metaSCOREc jest osobną, wycofaną aplikacją; przeniesienie jej projektów wymaga osobnego sprawdzenia. To pilotaż, nie wydanie produkcyjne 1.0.
